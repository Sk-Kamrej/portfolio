# SK Nexus

Create a modern, premium, highly interactive personal portfolio website for me as a BCA Honours with Research student, aspiring software developer, AI/ML researcher, and future technology professional.



The website should NOT look like a generic student portfolio or a basic template. It should feel like a real professional developer/researcher portfolio that could be used when applying for internships, jobs, research opportunities, MCA programs, and collaborations.



Overall Design Direction



Create a visually impressive, modern, minimal, professional interface with:



- Dark-first modern design

- Clean typography

- Subtle gradients

- Glassmorphism used sparingly

- Smooth micro-interactions

- Elegant hover effects

- Scroll-based animations

- Soft glowing accents

- Modern cards with subtle borders

- Excellent spacing and visual hierarchy

- Mobile-first responsive design

- Professional but slightly futuristic developer aesthetic



Avoid excessive neon effects, excessive animations, childish UI, or generic portfolio templates.



The website should feel inspired by modern SaaS/developer websites rather than a college project website.
